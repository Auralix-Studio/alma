# Descargador de TikTok

Aplicación de ejemplo en Alma: consulta la API pública de `tikwm.com` para obtener
los datos de un video, buscar videos y listar tendencias. Muestra `red`, `json`,
diccionarios anidados, `para` e `intentar`/`capturar` en un programa real.

## Ejecutar

Desde esta carpeta (requiere conexión a internet):

```
alma ejecutar principal.alma
```

Las URL y consultas se codifican con `red.codificar_url` antes de enviarse.
