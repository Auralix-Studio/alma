Valor frente a Referencia

Eliminación de efectos secundarios imprevistos mediante contratos semánticos explícitos en tiempo de diseño:

estructura • Semántica por Valor COPIA EN STACK 
estructura Vector3D
    x: decimal
    y: decimal
    z: decimal
fin

funcion principal()
    a = Vector3D(1.0, 2.0, 3.0)
    b = a            // 'estructura' realiza copia profunda
    b.x = 99.0
    imprimir(a.x)    // 1.0  — 'a' permanece invariante
fin
modelo • Semántica por Referencia PUNTERO COMPARTIDO 
modelo Contador
    total: entero

    funcion incrementar()
        total = total + 1
    fin
fin

funcion principal()
    c = Contador(0)
    d = c            // 'modelo' comparte la misma instancia
    d.incrementar()
    imprimir(c.total)  // 1  — 'c' refleja la mutación
fin

Introducción y Filosofía de Diseño

Alma es un lenguaje de programación de sistemas y propósito general, concebido en español, integrado en el ecosistema Auralix. Su objetivo es proporcionar herramientas de alto nivel de abstracción con control preciso de recursos y compilación independiente.

Regla Sintáctica Fundamental: Los bloques de código se delimitan por indentación y se cierran de manera explícita con el término fin. La gramática no emplea terminadores de sentencia punto y coma. Las notas de desarrollo utilizan el prefijo //.

Piso bajo, techo alto

El diseño permite una curva de aprendizaje inicial directa mediante identificadores naturales (si, mientras, funcion, imprimir) manteniendo capacidades avanzadas: gestión de copia de memoria por valor frente a referencia, análisis semántico gradual y compilación binaria sin toolchains pesados.

Punto de Entrada y Estructura

El punto de entrada convencional para aplicaciones ejecutables es la función principal():

funcion principal()
    imprimir("Inicio de ejecución en Alma")
    identificador = "Modulo_01"
    imprimir("Sub-sistema: " + identificador)
fin

Ejecución desde el terminal:

alma ejecutar principal.alma

Tipado Gradual y Constantes

Alma implementa un sistema de tipado gradual que permite la coexistencia de inferencia dinámica y anotaciones estáticas:

nombre = "Auralix"         // Inferencia de texto
edad: entero = 24          // Anotación estática de 64 bits
precio: decimal = 99.95    // Punto flotante f64
activo: logico = verdadero  // Booleano (verdadero / falso)
sin_dato: nulo = nulo      // Representación de valor nulo

// Declaración inmutable evaluada estáticamente
fijo LIMITE_BUFFER = 4096

Estructura (Valor) vs. Modelo (Referencia)

Definición del modelo de memoria del lenguaje:

  • estructura: Tipo de datos con semántica por valor. La asignación genera una duplicación independiente de la memoria.
  • modelo: Tipo de datos con semántica por referencia. Las asignaciones comparten el mismo puntero a la instancia activa.
